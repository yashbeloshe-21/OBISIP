# Task 1 – Exploratory Data Analysis on Retail Sales Data

## Internship
Oasis Infobyte Internship Program

## Domain
Data Analytics

## Objective
Perform Exploratory Data Analysis on a retail sales dataset to discover sales trends, customer behaviour, and business insights.

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Analysis Performed
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Descriptive statistical analysis
4. Monthly and quarterly sales analysis
5. Customer demographics analysis
6. Product category analysis
7. Correlation heatmap
8. Day-wise sales analysis
9. Business recommendations

## Project Files
- EDA.ipynb – Jupyter Notebook containing the analysis.
- retail_sales_dataset.csv – Dataset used for analysis.
