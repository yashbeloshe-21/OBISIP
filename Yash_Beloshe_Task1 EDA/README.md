## 🎯 Objective

Perform Exploratory Data Analysis on a retail sales dataset to uncover sales patterns, customer behaviour trends, and actionable business insights.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📁 Project Files

| File | Description |
|---|---|
| `EDA.ipynb` | Jupyter Notebook containing the complete analysis |
| `retail_sales_dataset.csv` | Retail sales dataset |
| `README.md` | Project documentation |

## 🔍 Analysis Performed

1. Dataset loading and initial inspection
2. Data cleaning and preprocessing
3. Descriptive statistical analysis
4. Monthly sales trend analysis
5. Quarterly sales trend analysis
6. Customer age distribution and age groups
7. Gender distribution analysis
8. Product category sales analysis
9. Revenue by product category
10. Correlation heatmap
11. Day-wise sales analysis
12. Business insights and recommendations

## 📈 Key Business Insights

The analysis explores:

- Sales performance across months and quarters.
- Customer distribution by age and gender.
- Product category sales and revenue contribution.
- Relationships between numerical variables.
- Differences in sales across weekdays.

## 💡 Business Recommendations

- Optimize inventory based on high-demand categories.
- Develop targeted marketing strategies using customer demographics.
- Prioritize high-revenue product categories.
- Plan promotional campaigns during weaker sales periods.
- Use historical sales trends to improve business planning.

## ▶️ How to Run the Project

1. Clone or download this repository.
2. Install the required Python libraries:

```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Open Jupyter Notebook.
4. Open `EDA.ipynb`.
5. Ensure the CSV dataset is in the same folder as the notebook.
6. Run all notebook cells sequentially.

## 📌 Conclusion

This project demonstrates the application of Python-based Exploratory Data Analysis to understand retail sales performance and customer purchasing behaviour.

The findings provide useful insights that can support data-driven business decisions, marketing strategies, and inventory planning.
